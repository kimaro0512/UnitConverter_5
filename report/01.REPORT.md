## 1. Executive Summary

README(PRD)와 레거시 `UnitConverter.py`를 대상으로 **Mom Test → PRD 갭 분석 → OCP/SRP 아키텍처 SPEC → Dual Track TDD + BCE TC 설계**까지 완료했다.  
가짜 PRD(“CLI를 PRD·테스트로 추적 가능하게 재구현”)는 **End User 문제가 아닌 Solution-first PRD**임을 검증했고, 실습 목적(설계·TC·리팩토링 학습)으로 **Problem Statement를 재정의**했다.

## 2. Mom Test (Track 1 — Discovery)

### 가짜 문제 (검증 대상)

> 길이 단위 변환 CLI를 PRD와 테스트로부터 추적 가능하게 재구현한다.

**판정:** End User 관점 ❌ 가짜 | 워크샵/조직 관점 ✅ 부분적 진짜

### 진짜 문제 (우선순위)

| # | Problem | Who |
|---|---------|-----|
| 1 | 5초 안에 신뢰할 수 있는 변환 (속도·정밀·마찰) | 현장·DIY·엔지니어 |
| 2 | feet/inch 복합 표기 한 번에 처리 | DIY·건설 |
| 3 | 문서·슬랙용 출력 포맷 (JSON/표) | 개발자·보고서 |
| 4 | 추적 가능한 설계·TC로 리팩토링 **연습** | 실습 참가자 |

### Problem Statement (실습 PRD — 채택)

> 하드코딩된 변환 스크립트를 요구사항·테스트·설정 파일과 추적 가능한 구조로 바꾸며, 확장 시 코드 변경을 최소화하는 설계를 익힌다.

## 4. 아키텍처 SPEC (OCP / SRP)

목표 패키지 `unit_converter/` (Entity / Control / Boundary 레이어):

- `domain/` — Quantity, ConversionResult, exceptions  
- `conversion/` — UnitRegistry, ConversionEngine (meter hub)  
- `input/` — parser, validator  
- `output/` — formatters (text/json/csv/table)  
- `app/` — ConversionService, cli  

**상세:** [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)
